Invisible to Visible: test pages

Serve this folder with python -m http.server 8001 from testpages/ and open http://localhost:8001/. Each page triggers one kind of call a known number of times. Open each page in a freshly loaded tab, wait about 15 seconds, then expand its row in the dashboard.

  • hooks.html: canvas, WebGL, audio, fonts, location
  • cookies.html: cookies set by scripts (and a name that repeats)
  • frames.html: hooks inside a srcdoc iframe and an about:blank iframe
  • hostile.html: floods and forged messages (counts must stay within the caps)
  • quiet.html: calls nothing; should show no calls observed
