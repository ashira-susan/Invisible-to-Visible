Before anything is recorded

Invisible to Visible shows you what happens behind the pages you open. This first version does one small thing.

What it records

The name of each website you open (for example news.example.com), whether it used HTTPS, and the time.

What it never records

Page addresses beyond the site name, page titles or content, passwords, form entries, or anything you type.

Where it goes

To the Invisible to Visible server running on this computer (127.0.0.1). It is not sent anywhere else.

Your control

Pause recording from the toolbar icon at any time. Delete everything stored from the dashboard. If a later version wants to collect more, it will ask you again first.
