Before anything is recorded

Invisible to Visible shows you what happens behind the pages you open. You choose how much it sees.

Always recorded, if you allow anything

The name of each website you open (for example news.example.com), whether it used HTTPS, and the time.

Also, if you allow tracker detection

While a page loads, the extension watches the addresses of the requests it makes to other sites. It keeps only how many there were and the names of known tracking companies among them (for example doubleclick.net, operated by Google). Every other address is forgotten as soon as the page's summary is made.

It also counts how many cookies the page and other sites set during the visit, and how many of those come from known trackers. Cookie names and values are never kept or sent. And it notes which site you arrived from, for example https://www.google.com, without the page or search you came from.

To do this, Chrome will ask you to allow access to all websites. Chrome words that request broadly. This extension only observes request addresses. It does not read page content, change pages, or block anything. You can take the access back later in Chrome's extension settings.

Never recorded

Full page addresses beyond the site name, page titles or content, passwords, form entries, or anything you type.

Where it goes

To the Invisible to Visible server running on this computer (127.0.0.1). It is not sent anywhere else.

Your control

Pause recording from the toolbar icon at any time. Delete everything stored from the dashboard. If a later version wants to collect more, it will ask you again first.
